# Bam'S Market

## Description

Bam'S Market est une plateforme de marketplace destinée aux commerçants et consommateurs de Madagascar.

### Objectif

Créer une plateforme évolutive intégrant GoalPay comme premier moyen de paiement, avec la possibilité d'ajouter d'autres solutions de paiement à l'avenir.

### Technologies prévues

- Frontend : Next.js
- Backend : NestJS
- Base de données : PostgreSQL
- ORM : Prisma
- Paiement : GoalPay
